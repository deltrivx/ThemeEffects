# 更新日志

## v2.5.0-Beta2 - 2026-07-29

### 概述
**鼠标特效 Beta2**。引擎常驻加载（可即时开关）、空闲淡出、新增「星火」样式、设置页改选项即时预览。

### 变更
- **常驻加载**：未开「减少动效」时始终加载 `ucwc-mouse-fx.js`，由 `MOUSE_FX` 控制运行（无需整页重装脚本）
- **空闲淡出**：光标静止约 0.9s 后柔和消失，移回即恢复
- **新样式 spark（星火）**：移动溅射微粒 + 点击爆发
- **自动色**：自定义色为空时读取主题 accent CSS 变量（回退青）
- **设置页即时预览**：改开关/样式/大小/强度/颜色即生效；「应用」仍负责落盘
- 版本号：**v2.5.0-Beta2**（beta；`latest_version` 仍为 v2.4.3）
