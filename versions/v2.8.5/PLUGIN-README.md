# 主题特效（Theme Effects）

适用于 Unraid 6.12+ 的独立 WebGUI 视觉增强插件。

## 核心能力

- 全局主题、壁纸、模糊与响应式布局
- 粒子、鼠标动效和多套全站指针
- 内置或自定义 GIF 吉祥物
- 字体、字号、颜色和本地字体文件
- Community Applications 页面增强
- 浏览器与 Unraid 本地路径双路资源上传
- Release 双重 SHA256、差异 OTA、全量修复与 flash 离线恢复

## 使用入口

安装后前往：**设置 → 用户偏好 → 主题特效**

升级会保留用户配置和上传资源，并清理 Theme Effects 自身的过期残留。
